# PalmVein Site

Site estático da PalmVein pronto para deploy na Vercel.

## Estrutura

- `index.html`: página principal
- `_imagens/`: imagens usadas no site
- `assets/`: assets auxiliares
- `vercel.json`: configuração simples para deploy estático

## Deploy na Vercel

1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel, importe o repositório.
3. Use as configurações padrão de projeto estático.
